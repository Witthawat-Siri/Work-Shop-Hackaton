# เที่ยวไหนดี? — Find Your Trip

เว็บไซต์ Next.js สำหรับค้นหาและค้นพบสถานที่ท่องเที่ยวไทยจากชุดข้อมูลตัวอย่าง

## Run locally

```bash
npm install
npm run dev
```

จากนั้นเปิด [http://localhost:3000](http://localhost:3000)

## ฟีเจอร์ใน MVP

- ค้นหาสถานที่จากชื่อ จังหวัด หรือคำอธิบาย
- กรองตามภูมิภาคและสไตล์การเที่ยว
- สุ่มที่เที่ยวจากผลลัพธ์ที่เลือก
- บันทึกสถานที่ที่สนใจไว้ชั่วคราวในหน้าเว็บ
- ดูรายละเอียดและเปิดพิกัดใน Google Maps
